# Make a Deep Net Converge in PyTorch

Chapter 11 of Hands-On Machine Learning as a debugging session: start from a deep sigmoid network that barely learns, measure its vanishing gradients layer by layer, then fix it one change at a time with He initialization, ReLU, batch normalization, dropout, a better optimizer and one-cycle scheduling. Finish with transfer learning.

## How to run

```bash
python scaffold.py
```
